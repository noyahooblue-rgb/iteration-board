# 脚本重检清单（1.1.0，2026-11-24）

> 对象：`packaging/windows/` 全部 12 个 .bat + 运行时生成的 `merge-migration.bat`（见 §4）+ `tools/check-bat.py` 新规则 R1–R6（另见 `docs/check-bat-新规则清单与命中修复记录.md`）。
> 基线 973231d → 本轮提交。验证方式：check-bat 全绿 + 逐行人工复核 + 标签/goto 目标/括号配平静态自查。**本机为 Linux，未真跑 .bat，不声称真机验证**；批处理语义结论均为静态复核结论，真机回归留待 CI 档 2/档 3 与真机验收。
> 统一脚本契约（本轮落地，规范全文见 `docs/Windows脚本编写规范.md`）：IB_AUTO=1 不 pause、不提问；IB_YES=1 确认默认肯定；每脚本写 `<脚本名>-yyyyMMdd-HHmmss.log` 到脚本所在目录，关键行经 `:log` 双写，结束经 `:ib_pause` 打印日志路径；人工双击经 IB_WRAPPED 外壳以 `cmd /k` 重启自己，IB_AUTO=1 不套外壳。

图例：**已修** = 本轮发现问题并修复；**有** = 检查过、本来就合规/机制在位；**无** = 该类问题不存在或不适用（附理由）；**遗留** = 已知未改、附理由与后续。

## §1 矩阵：脚本 × 13 类问题

13 类：①括号块路径变量 ②路径引号与特殊字符 ③默认值指向错误目录+说明与实际一致 ④窗口不直接关闭 ⑤提权与 System32 工作目录 ⑥errorlevel 时机 ⑦set-p 读空与延迟展开吞 ! ⑧内嵌 PowerShell 传参 ⑨编码代码页 ⑩%TEMP% 残留 ⑪幂等与中断恢复 ⑫文件占用重试 ⑬返回码。

## §3 两行专项结论

| 项 | 结论 |
|---|---|
| 覆盖前备份 | **机制在位，本轮加固**。DB 备份复用既有 backup.bat 口径：`pg_dump -Fc` 生成 db.dump 到配置的 backup.dir（默认 `<安装>\backup`）下时间戳目录并写 `data\backup-status.json`；apply-patch/upgrade 在停服与覆盖前先 call 目标 backup.bat，再校验 15 分钟内的新鲜 db.dump，缺失即中止（既有）。程序备份：rollback bundle 位于 `<backup.dir>\upgrade-<yyyyMMdd-HHmmss>\`（upgrade-info.txt + files\）——apply-patch 原只备份「将被替换的文件」，**本轮追加整 `app\` 目录 + `version.txt`**，robocopy/copy 失败即中止补丁；upgrade 的 bundle 原已含 jar + 全部 .bat + prompts。**命名口径说明**：未新造 `backups\pre-patch-<版本>-<时间戳>\` 目录——rollback.bat 按现有 bundle 契约（目录名 upgrade-*、upgrade-info.txt 字段）读取，改名即断回滚链；「DB + 程序双备份、失败即中止」的实质已满足，差异在此明示 |
| config 不被覆盖 | **结论：用户改过的 `config\application.yml`（端口/DB 密码）不会被补丁或升级覆盖**。证据：upgrade.bat 的复制清单只有 jar、config\prompts、version.txt 与 .bat，从不复制 application.yml；apply-patch 的复制由 SHA256SUMS 清单驱动，基线下若补丁清单列入 config\application.yml 理论上会被覆盖——**本轮在复制命令内加硬守卫：该文件永不覆盖，命中时打 [WARN] 并跳过**（其余文件照常校验复制）；install.bat 仅在无 `.installed` 标记时生成 config（既有）；migrate-import 只按白名单键（port + AI 连接）合并导出设置、写后校验、本机 DB 密码保留（台账第 8 条） |

## §4 分卷合并脚本（merge-migration.bat）

- 先查 `packaging/build-package.sh`：**打包脚本不生成任何合并 .bat**——它只把 12 个 .bat 逐个 `cp` 进 staging（第 323 行附近的循环），无模板、无拼接。
- `merge-migration.bat` 是 **migrate-export.bat 在分卷时用内嵌 PowerShell 模板（`$lines` 数组）运行时生成**的，模板在仓内（migrate-export.bat 分卷段），故已纳入本轮矩阵与修复：
  - 编码：WriteAllText 以 ASCII 写入、行间以 CRLF 拼接 ✓
  - 路径：`set "DIR=%~dp0"` 与 `copy /b "%%DIR%%..."` 均已引号 ✓；无括号块、无 %TEMP% ✓
  - 窗口：原模板末尾裸 `pause`，本轮改为 `if not "%IB_AUTO%"=="1" pause`，自动化场景不卡住 ✓
  - 无外壳/日志/提权：合并分卷只是拼接文件 + certutil 验哈希，不动服务与系统，**不需要**管理员与外壳，记为「无（理由）」
  - check-bat R6 对其生成行有 1 条豁免（模板字符串数据，见 check-bat 记录第 2 条）
