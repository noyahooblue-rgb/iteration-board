# 迭代小组平台 1.1.0 升级说明

适用对象：已在用的安装（1.0.1 / 1.0.4 / 1.1.0-rc4）。全新安装请直接用全量包
`iteration-board-offline-1.1.0.zip` 按随包《部署手册》安装，不看本文。

## 一、选哪个包

| 当前版本 | 用哪个包 |
| --- | --- |
| 1.1.0-rc4 | `iteration-board-patch-1.1.0-rc4-to-1.1.0.zip` |
| 1.0.4 | `iteration-board-patch-1.0.4-to-1.1.0.zip` |
| 1.0.1 | `iteration-board-patch-1.0.1-to-1.1.0.zip`（累积包，一步到位） |
| 1.0.2 / 1.0.3 等更早版本 | 先逐级打旧补丁升到 1.0.4，再用 1.0.4 的包升 1.1.0 |
| 还没装过 | 全量包 `iteration-board-offline-1.1.0.zip` 全新安装 |

补丁包与全量包的核心程序逐字节一致（发布时已做 SHA-256 比对），不存在「补丁版功能少」的问题。

## 二、升级步骤（补丁包）

1. 把补丁 zip 解压到一个普通文件夹（不要在 zip 里直接双击脚本）。
2. 双击里面的 `apply-patch.bat`，或在命令行运行 `apply-patch.bat <安装目录>`。
   - 不带参数运行时，脚本会尝试从已注册的服务自动找到安装目录；找到唯一一个会显示出来让你确认，找不到或有多个时会请你手动输入。
   - 脚本会自动请求管理员权限；路径里有空格、括号都没关系。
3. 脚本会依次：校验安装目录 → 停服务 → 等旧程序完全退出 → **自动备份** → 覆盖程序 → 启服务 → 自检。全程有日志文件（脚本同目录，文件名带时间戳）。
4. 浏览器打开平台，版本号显示 1.1.0、能正常登录即升级完成。第一次登录新版会弹一次「版本更新说明」，看完点「知道了」即可。

## 三、升级前自动备份与回滚（重要）

打补丁前脚本自动做两份备份，缺一不继续：

- **数据库**：调用安装目录的 `backup.bat auto` 做一次新备份（pg_dump 自定义格式）；已有备份若是 15 分钟内的新鲜备份则直接采用。备份失败或过期，脚本停下报错，不动任何文件。
- **旧程序**：整个 `app\` 目录 + `version.txt` 复制为安装目录下 `rollback-<日期时间>\` 文件夹。

万一升级后要回滚：

1. 停服务（`stop.bat`）。
2. 数据库：用 `rollback-<日期时间>\` 同批次的数据库备份恢复（`restore.bat` 选该备份）。
3. 程序：把 `rollback-<日期时间>\app\` 覆盖回安装目录 `app\`，`version.txt` 一并还原。
4. 启服务（`start.bat`），确认回到旧版本。

注意：**数据库升级后不能只换回旧程序**——必须程序和数据库一起回滚，否则旧程序读不了新结构。

## 四、不会被动到的东西

- `config\application.yml`（你的配置，含 AI 接口等设置）**永远不被补丁覆盖**：补丁包里带了新版模板也只会跳过并打 `[WARN]` 提示，升级后请对照模板人工看一眼有没有新增配置项需要补。
- 数据库数据、上传的文件、备份文件都不在补丁覆盖范围内。
- 用户账号与密码不变；但注意 1.1.0 的密码规则加强只对「新设的密码」生效，老密码照常能登录。

## 五、常见提示

- **Windows SmartScreen / 杀毒软件拦截**：脚本与程序未做商业代码签名，首次运行可能弹「Windows 已保护你的电脑」——点「更多信息 → 仍要运行」即可；这是未签名软件的例行提示，不代表文件有问题（可用 SHA256SUMS.txt 核对文件完整性）。
- **双击脚本一闪而过**：1.1.0 起脚本带防闪退外壳，正常情况不会再发生；若仍闪退，请在脚本目录打开命令行手动运行同名脚本，窗口会保留报错信息，日志文件也在同目录。
- **升级后页面还是旧样子**：浏览器强制刷新一次（Ctrl+F5）；长期开着的旧标签页请关掉重开。
- **更新说明弹窗关不掉**：1.1.0 已修（弹窗限高 + 内部滚动）；若在矮屏上仍异常，先按 Esc 或刷新页面，再到「系统信息页」里重看更新说明。
