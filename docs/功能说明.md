# 迭代小组平台 · 功能说明

迭代小组平台是一款面向 Scrum 小组的协同看板工具：一个小组在同一个工作区里管理迭代、事项、进展与报告，数据保存在自有 PostgreSQL 数据库中，可完全离线部署在局域网环境。

## 角色

- **组长（LEADER）**：管理小组与成员、迭代生命周期、小组设置、提醒扫描、对接配置。
- **产品负责人（PO）**：管理任务与故事、批量下发、导入确认、验收相关操作、AI 拆故事。
- **成员（MEMBER）**：认领与推进事项、登记进展、评论、催办回应。
- **平台管理员**：首个注册账号自动成为平台管理员，负责平台级开关（如 AI 总开关）。

## 功能模块

- **工作台与看板**：按状态列展示当前迭代事项，支持拖拽流转、筛选、子事项进度、阻塞标记与催办缎带。
- **事项管理**：任务 / 故事 / 缺陷 / 分析 / 临时事项五种类型；共同负责人、检查清单、评论、进展登记、状态机流转（见 `contract/state-machine.md`）。
- **迭代管理**：迭代创建、规划、开始与结束、关键日期、燃尽快照、迭代总结与结转。
- **协作**：组长总览、站会页、通知中心（SSE 实时推送与偏好设置）、催一下与自动提醒、风险信号。
- **报告**：站会摘要、周报、迭代总结、个人周报、风险摘要；支持编辑、历史版本、回收站与 Excel 导出。
- **回收站**：事项与报告软删除后统一进入回收站，可恢复。
- **接口契约**：`contract/openapi.yaml` 为唯一接口契约来源，真实后端与浏览器模拟后端共同遵循。

## AI 能力

平台内置 AI 服务层（可整体关闭，小组可逐项开关），模型只给出建议，写入一律走既有业务服务与状态机：

1. 粘贴导入：把粘贴的文本解析为结构化事项草稿，确认后写入。
2. 一句话更新：把一句自然语言解析为对既有事项的更新建议。
3. 自动汇总：程序计算事实表，模型只撰写叙述文字。
4. 拆故事：把大故事拆为子故事草稿（仅 PO 可用）。
5. 风险摘要：基于规则计算的风险信号生成摘要报告。
6. 智能问答：基于小组事项数据回答问题并给出引用。

AI 接入方式为 OpenAI 兼容接口，通过环境变量配置地址、密钥与模型名；未配置真实模型时可使用内置 mock 模式返回结构化样例结果。`tools/ai-eval/` 提供了一套独立的提示词回归评测脚本，可在部署环境中用真实模型对六项功能做批量验证。

## 对接与导入

- **外部系统对接**：可配置 HTTP 通用适配器（地址、请求头、字段映射），支持测试连接、立即同步与同步日志；同步连续失败达到阈值时会通知全部组长。另内置 mock 适配器提供虚构样例数据。
- **文件导入**：支持 Excel / CSV 文件解析导入，以及粘贴文本经 AI 解析导入；导入先生成批次草稿，确认后才写入，整批可撤销，并支持幂等键防重复提交。

## 演示数据

仓库内的模拟后端（`mock-backend/`）包含一套全虚构演示数据（虚构小组「云雀小组」与 9 名虚构成员），仅用于演示构建，不进入真实后端与正式构建产物。演示账号口令的设置方法见根 README。
