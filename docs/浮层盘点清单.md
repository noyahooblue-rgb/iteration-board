# 浮层盘点清单（修订五 A）

盘点日期：2026-11-20。范围：`frontend/src` 全部下拉/选择器/日期/@提及/更多菜单/悬浮提示/面板/命令面板。

## 统一浮层组件

`frontend/src/components/OverlayMenu.vue`（修订五新建）：

- Teleport 到 `body` 顶层渲染，不放在抽屉、弹窗、卡片、表格单元格内部；
- 实色 `var(--bg-raised)` 不透明背景（浅色 #ffffff / 深色 #1c2742，随主题变量），1px `var(--line)` 描边，`var(--shadow-3)` 阴影，**禁止 backdrop-filter**；
- 打开时几何自检：贴触发元素；水平越界翻转对齐/平移，垂直空间不足下→上翻转；平移保证完整在视口内且距边缘 ≥ 8px，仍放不下时限高滚动；
- 滚动/缩放时跟随重定位；点外部关闭；Esc 在捕获阶段先关浮层（不关抽屉/弹窗）；↑↓ 键移动焦点、Enter 选择（原生按钮语义）、Esc 关闭；关闭后焦点回触发元素；`manualFocus` 模式不抢焦点（@提及列表专用，焦点须留在输入框）。

## z-index 档位令牌（tokens.css）

| 变量 | 值 | 用途 |
|---|---|---|
| `--z-page` | 0 | 页面内容 |
| `--z-sticky` | 10 | 粘性元素/卡片角标 |
| `--z-chrome` | 20 | 侧栏、顶栏 |
| `--z-drawer` | 30 | 抽屉（Drawer） |
| `--z-modal` | 40 | 弹窗（Modal）、命令面板 |
| `--z-overlay` | 50 | 浮层（OverlayMenu） |
| `--z-toast` | 60 | 提示条（ToastHost） |

写死 z-index 排查结果：原有写死值共 10 处（ToastHost 100、CommandPalette 80、Modal 70、Drawer 60、AppShell 顶栏 20/小组菜单 30/用户菜单 40/通知面板 60、ItemDrawer 菜单 5/内联浮层 40、MentionInput 60、BoardView 角标 1、base.css 页面背景 -1），除页面背景 -1（背景层，非浮层，保留并在此登记）外已全部改为令牌。
