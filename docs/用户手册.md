# 迭代小组平台 · 用户手册

本手册面向日常使用者：如何注册登录、建组协作、用看板推进事项、用迭代与报告复盘，以及六项 AI 功能的用法。文中人名、组名均为虚构示例。

## 1. 注册与登录

1. 打开平台地址（向管理员索取，如 `http://192.168.1.50:18080/`）。
2. 首次使用点「注册」：填写用户名、显示名与密码完成注册。**全平台第一个注册的账号是管理员**，普通使用者正常注册即可。
3. 之后用用户名 + 密码登录；登录状态保持一段时间，换电脑需重新登录。
4. 在登录页可使用图形验证码刷新；连续输错密码会被短暂锁定，稍后再试。
5. 退出登录在右上角头像菜单里。

## 2. 建组与入组

- **建组**：登录后若还没有小组，会直接进入「创建小组」页：填小组名称（例如「星桥小组」）后创建，创建人自动成为组长。小组有一个唯一组代码，用于邀请与导入时识别小组。
- **入组**：已有小组的同事，注册后由组长在「小组设置 → 成员」中添加，或按组长给的邀请方式加入；加入后在顶部小组切换器里切换当前小组。
- **待处理页**：收到加入申请/邀请时，会在「待处理」页集中处理。
- 角色说明：组长负责小组设置、成员与迭代管理；产品负责人（PO）负责需求池与优先级；普通成员认领和推进事项。一个人可以在多个小组里是不同角色。

## 3. 事项与看板

**事项**是平台的基本工作单元，分「任务」与「用户故事」两类，有编号（如 `IB-12`）、标题、描述、优先级、估算、经办人、关注人、标签、截止日期与检查清单。

- **新建事项**：在看板或需求池点「新建」，或在任意页面用快捷键呼出搜索后创建；标题必填，其余可后补。
- **看板**：事项按状态分列（待处理 → 进行中 → 待验收 → 已完成等，以小组设置为准）。拖动卡片即可变更状态；卡片上显示优先级、经办人头像与截止提醒，逾期会标红。
- **事项详情**：点卡片进入详情页，可编辑全部字段、管理检查清单、写评论、@ 同事、上传图片附件、查看变更历史。评论与字段变更会通知经办人与关注人。
- **搜索**：顶部搜索框（或 `Ctrl+K`）按编号、标题关键词全局搜索事项。
- **工作台**：登录首页汇总「我负责的」「我关注的」「待我验收」与近期动态，先看这里再开工。
- **总览**：按成员/状态统计小组整体进展与风险分布。

## 4. 认领池（需求池）

需求池（规划页/需求池）存放尚未排期的想法与需求：

1. 任何成员都可以把事项放进需求池，写清背景与价值。
2. PO 与组长在需求池里评审、定优先级、补估算；评审通过的事项进入迭代规划。
3. **认领**：开放认领的事项，成员在认领池点「认领」即成为经办人并进入进行中；认领后如需转交，在事项详情里改经办人即可。
4. 长期无人认领的事项会沉底显示，评审时决定保留、拆分或移入回收站。

## 5. 进展与催更

- **更新进展**：在事项详情写评论即是进展记录；也可以用 AI「速记更新」（见第 8 节）把一句话口述转成结构化进展。
- **站会页**：按成员汇总昨日完成、今日计划与阻塞，站会时直接投屏这一页。
- **催更**：对停滞事项，任何关注人可在详情页点「催更」，经办人会收到一条带事项链接的提醒通知；通知中心（顶部铃铛）汇总催更、@ 与验收提醒，未读数会标红。
- **验收**：事项进入「待验收」后，由创建人或 PO 在详情页验收通过/打回，打回需写明原因。

## 6. 迭代

1. 组长/PO 在「迭代」页新建迭代：命名（如「2026 年 1 月迭代」）、设起止日期。
2. 从需求池把已评审事项加入迭代，或直接在迭代里新建事项；迭代页显示总量、已完成量与燃尽趋势。
3. 迭代进行中可增减事项（会有记录）；迭代结束时点「完成迭代」，未完成事项选择顺延到下一迭代或退回需求池。
4. 历史迭代可回看，用于复盘与报告取数。

## 7. 报告

「报告」页按迭代或时间范围生成小组报告：

- 内容含完成情况、事项清单、成员工作量、风险摘要；
- 可在线预览，也可导出 Excel 文件留档或上报；
- 报告数据来自事项与进展记录，导出前请确认本迭代事项状态已更新完毕；
- 报告仅组长与 PO 可见完整版（含风险部分），普通成员看到与自己相关的部分。

## 8. AI 六项功能

AI 功能需管理员先完成平台配置（见《部署手册》第 5 节），并在小组设置中开启对应项；未开启的功能入口不显示或显示为不可用。所有 AI 结果都是**草稿**，确认后才写入数据。

| 功能 | 在哪里 | 做什么 |
| --- | --- | --- |
| 粘贴导入 | 需求池 →「粘贴导入」 | 把一段会议纪要、清单文本（也可上传 Excel/CSV 文件）粘贴进去，AI 拆成多条事项草稿，逐条勾选、修改后批量建单。 |
| 速记更新 | 事项详情 →「速记更新」 | 输入一句口语化进展（如「登录页联调完了，还差异常提示」），AI 转成结构化进展（完成项/待办/风险），确认后写入评论。 |
| 拆分故事 | 用户故事详情 →「拆分故事」 | 把一个大故事拆成若干子任务草稿（含标题与估算建议），勾选后批量创建并关联原故事。 |
| 事项摘要 | 事项详情 →「摘要」 | 对评论多、周期长的事项生成一段摘要：目标、当前进展、关键决定、遗留问题，快速接手不用翻楼。 |
| 风险摘要 | 总览/报告页 →「风险摘要」 | 汇总本迭代逾期、阻塞、无人跟进等风险点成清单（仅组长与 PO 可见）。 |
| 知识问答 | 顶部「问答」页 | 用自然语言提问（如「上个迭代为什么延期？」），AI 基于本组事项与评论作答并给出引用来源；问答历史可回看。注意：AI 只能看到当前小组的数据。 |

使用提示：AI 结果请先核对再确认，尤其是数字与日期；发现答非所问时，换个问法或补充上下文通常能改善。

## 9. 回收站

- 删除的事项先进回收站，不会立即消失；「回收站」页可**恢复**（回到删除前状态）或**彻底删除**（不可恢复，谨慎操作）。
- 彻底删除一般仅组长可执行；误删后第一时间去回收站恢复即可，不要重复建单。

## 10. 审计日志

- 「小组设置 → 审计日志」记录关键操作：谁在何时创建/修改/删除了事项、改了成员与设置、导出了报告等（仅组长可见）。
- 出问题时先查审计日志定位操作人与时间，再决定恢复方式（回收站恢复、报告对照等）。
- 审计日志只读，不能编辑或删除。

## 11. 个人设置

点右上角头像 →「个人设置」：

- **资料**：改显示名、头像与密码（改密码后其他设备需重新登录）。
- **通知**：按类型开关催更、@、验收等通知。
- **外观**：切换浅色/深色外观与界面密度（舒适/紧凑），设置立即生效并记住，下次登录保持。
- **我的小组**：查看所在小组与角色，切换默认进入的小组。

## 12. 快捷键

| 快捷键 | 功能 |
| --- | --- |
| `Ctrl+K`（Mac 为 `Cmd+K`） | 呼出全局搜索/命令面板，按编号或标题找事项 |
| `Esc` | 关闭当前弹窗/面板 |
| `Enter` | 在搜索框中确认搜索；在表单中提交（多行文本框内为换行） |

其余操作以鼠标点按与拖拽为主；看板拖拽在触屏设备上长按卡片后拖动。
