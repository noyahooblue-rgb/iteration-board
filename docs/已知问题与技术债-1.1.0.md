# 1.1.0 已知问题与技术债清单

随 1.1.0 正式版发布。每条注明影响与计划去向；不在此列的问题请走意见反馈或联系维护者。

## 已知问题（行为已确认，非缺陷或暂可接受）

1. **「无当前迭代」时接口返回 404**：没有任何进行中迭代时，`GET /api/v1/iterations/current` 返回 404，浏览器控制台会留一条 404 记录；页面本身已静默处理，用户无感。把该情形改为返回 200 空结果属于接口契约变更，**推迟到 1.1.1** 统一处理（冻结期经评审确认不在 1.1.0 临门变更契约）。
2. **小组设置页「加入申请」角标的统计口径**：设置页页签角标统计的是**当前小组**的待处理申请数；左侧边栏角标是**全部小组**的合计。两处数字在多小组场景下可能不一致，属当前口径设计，统一口径列为技术债。
3. **SmartScreen / 杀毒软件提示**：安装包内脚本与程序未做商业代码签名，Windows 首次运行时可能出现 SmartScreen 拦截提示，需点「更多信息 → 仍要运行」。文件完整性可用随包 SHA256SUMS.txt 核对。
4. **升级后旧标签页**：升级前已打开的浏览器标签页不会自动感知新版，点旧链接可能出现提示或跳转登录页；关掉旧标签页、重新打开即可。后续版本考虑加「版本已更新，请刷新」的显式提示。
5. **系统信息页不显示构建 Git 提交号**：页面只显示版本号与构建日期；从包反查具体提交靠打包清单（jar-manifest）与发布记录，列为展示债。

## 技术债（已登记，排期处理）

6. **数据库回滚无一键脚本**：补丁已做到升级前自动备份数据库 + 旧程序，但回滚仍需按《1.1.0 升级说明》三步人工执行（停服务 → 恢复数据库备份 → 还原旧程序）。数据库结构升级不可只换程序不换数据，此约束短期内保留。
7. **仅 HTTP、无内置 HTTPS**：当前定位为局域网内使用，走 HTTP 明文。需要加密传输的场景请在前面加一层反向代理终止 TLS；内置证书管理列为后续规划。
8. **桌面通知偏好保存在浏览器本地**：通知开关、提示音等偏好存在浏览器本地存储里，换浏览器或换电脑需重新设置，未做服务端同步。
9. **逾期提醒口径**：提醒规则按现有口径计算（未开始迭代内的事项不提醒等），个别边界口径（如请假期间到期事项的提醒归属）仍在收集使用反馈，后续版本统一梳理。
10. **早期版本存量枚举旧值**：个别早期版本写入的事项字段存在旧枚举值，新版已做兼容读取；迁移导出校验对这类存量值会给出警告而非阻断，彻底清洗列为后续数据治理项。
11. **多团队角标口径统一**（同已知问题 2）：设置页与侧边栏的角标统计口径统一改造，随后续版本处理。

## 不在此列（已核查排除）

- 曾怀疑「个别非 /api 路径在未登录时可达」——经逐项核查（1.1.0-rc3 结论代码 C3），不存在该问题：未登录时除登录、注册、健康检查等白名单外一律拦截，事项处置代码/标题等敏感字段仅向有权用户返回。故不列入已知问题。
