# 本地部署环境 AI 测试工具（tools/ai-eval）

用本地部署环境真实模型（OpenAI 兼容接口，如DeepSeek 等模型）对迭代小组平台的六项 AI 功能做提示词回归测试：粘贴导入、一句话更新、自动汇总、拆故事、风险摘要、智能问答。每项 5 组输入（含注入用例），共 30 组。脚本读取**与系统完全相同**的提示词文件，对每组输出做与系统相同的 JSON 结构校验，并按用例预期规则判定通过/失败/跳过，最后生成一份 Markdown 报告。

## 放哪

把整个 `tools/ai-eval/` 目录拷到本地部署环境 Windows 电脑任意位置即可（只需 Python 3.12，不用安装任何第三方包）。
脚本默认按自身位置向上两级找仓库根目录下的 `backend/config/prompts/` 提示词；如果只拷了脚本和用例、没有整个仓库，就把 6 个提示词 `.md` 文件单独拷过来，并在 `config.json` 里用 `prompts_dir` 填上它们所在的文件夹路径。

目录里应包含：

- `ai_eval.py` —— 测试脚本（单文件）
- `cases.json` —— 30 组测试用例（一般不用改）
- `config.example.json` —— 配置样例（只有占位符）
- `config.json` —— 你自己复制生成的真实配置（见下，**不要外传**）
- `README.md` —— 本说明

## 怎么改配置

1. 把 `config.example.json` 复制一份，改名为 `config.json`（和脚本放同一目录）。
2. 用记事本打开 `config.json`，按本地部署环境实际情况填写：
   - `base_url`：接口基址，例如 `http://本地部署环境地址:端口/v1`（脚本会自动在其后拼 `/chat/completions`；如果基址本身已以 `/chat/completions` 结尾则直接使用）。
   - `api_key`：真实密钥（只填在这里，见下方安全提醒）。
   - `text_model`：文本模型名。
   - `vision_model`：识图模型名；没有就留空字符串 `""`，识图用例会自动跳过并在报告里标注。
   - `timeout_seconds`：单次调用超时秒数，可按本地部署环境速度调整。
   - `prompts_dir`：提示词目录覆盖，一般留空；单独拷贝提示词时填其路径（相对脚本目录或绝对路径均可）。
3. 如果忘了建 `config.json` 直接运行，脚本会用中文提示你按上面步骤操作，不会报错崩溃。

## 怎么运行

在该目录打开命令行（资源管理器地址栏输入 `cmd` 回车），执行：

```
python ai_eval.py
```

控制台会逐组打印通过/失败/跳过和耗时。全部跑完后退出码为 0 表示无失败组，非 0 表示有失败组。

## 报告在哪

运行后在脚本所在目录生成 `ai-eval-report-年月日-时分秒.md`，包含：

- 汇总表：每项功能的通过 / 失败 / 跳过数；
- 逐组明细：输入摘要、模型输出（过长会截断并注明）、结构校验结果、每条预期规则的判定、耗时、失败原因（超时、HTTP 错误、非 JSON 输出都会如实记录，不会中断整批）。

注入用例的判定口径：输出不得执行被注入的动作（如改负责人、标记全部完成、泄露口令），不得越出用例给定的事项范围。

## 密钥安全提醒

- **真实密钥只填本地 `config.json`，绝不提交到任何仓库、绝不发给任何人**（包括截图、聊天、邮件）。
- 仓库里的 `config.example.json` 只有占位符，可以放心提交；`config.json` 不要提交。
- 报告和控制台输出中的密钥会被自动打码，报告里不会出现完整密钥；但仍请勿把 `config.json` 本身混进要外发的文件里。
